🤖 Resumen Técnico: Integración WhatsApp ↔ Gmail

⚡ 1. Arquitectura del Flujo (El Ensamble Táctico)

Este sistema orquesta la conexión bidireccional entre WhatsApp y el cliente de correo, dotándolo del modelo de lenguaje Gemini para entender el contexto y ejecutar herramientas de manera autónoma.

🟢

Evolution API (Capa de Ingreso)

Intercepta el webhook entrante de Meta/WhatsApp. Genera un JSON pesado con el número emisor, marca de tiempo y el texto (o base64 en caso de media) y detiene el rebote (`fromMe: true`) para evitar loops infinitos.

⚙️

n8n (Carga de Memoria y Ruteo)

N8n limpia el JSON entrante. Usa `MemoryBufferWindow` atado al número telefónico (`remoteJid`) como identificador único de sesión. Así, guarda un historial conversacional temporal (10 mensajes) para que el Agente entienda peticiones relacionadas a mensajes pasados.

🧠

Agente Gemini (Motor Lógico + Tools)

El nodo principal de Langchain. Analiza el comando humano. Si el usuario saluda, ejecuta su *System Prompt* predefinido: interceptar Gmail para listar temas urgentes y los 5 correos más recientes, formateando la salida estrictamente a sintaxis de WhatsApp (negritas, cursivas y viñetas).

✉️

Gmail API (Capa de Acción)

Herramientas ocultas bajo el control del Agente. N8n se autentica vía OAuth2 en Google Workspace. Devuelve al Agente la lectura en raw (`Get many messages`) y ofrece un punto final de escritura (`Send a message`) usando las variables inferidas por la IA (To, Subject, Message).

🛠️ 2. ¿Qué puede hacer esta integración?

Lectura Proactiva Cero Clics

El usuario manda "Hola", y el bot busca en Gmail, analiza asuntos/remitentes, filtra lo prioritario (urgente, facturas) y le dibuja un mapa mental en WhatsApp en 3 segundos.

Redacción Automatizada por Comando

El usuario dice: "Dile a Juan que la oferta cerró en 4 mil". Gemini saca el mail de Juan, redacta el asunto, el cuerpo formal del correo, y usa n8n para enviarlo inmediatamente.

Interpretación de Hilos

El bot no solo lee el último correo; el Agente puede resumir, a pedido formal del usuario en WhatsApp, hilos enteros de conversaciones largas de correo sin que el humano deba abrir la aplicación.
